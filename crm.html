📱 סריקה ממכשיר נוסף
סרוק עם הנייד או לחץ "העתק קישור" — הגדרות הסנכרון יייבאו אוטומטית
הגדרה חד פעמית – 3 דקות (Firebase חינמי):
1. פתח console.firebase.google.com → צור פרויקט חדש
2. Build → Realtime Database → "Create database" → "Start in test mode"
3. העתק את כתובת הדאטאבייס (מתחילה בـhttps:// ומסתיימת בـfirebaseio.com) → הדבק למטה
אפשר למצוא אותה בקונסול Firebase: Realtime Database → כתובת בראש הדף
