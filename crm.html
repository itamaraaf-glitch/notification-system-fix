🛡️ גיבויים אוטומטיים

המערכת שומרת גיבוי מלא אוטומטית ברקע. בחר נקודת זמן לשחזור:

☁️ סנכרון ענן בין מכשירים

הסנכרון משתמש בFirebase Realtime Database (חינמי לגמרי) — כל שינוי במחשב מופיע מיידית בנייד ולהיפך.
הגדרה חד פעמית – 5 דקות:
1. פתח console.firebase.google.com ← "Add project" ← תן שם ← המשך
2. תפריט שמאל: Build → Realtime Database ← "Create database" ← "Start in test mode" ← Enable
3. לחץ ⚙️ (Project settings) ← "Your apps" ← סמל Web </> ← רשום שם ← "Register app"
4. העתק את כל תוכן ה-firebaseConfig (מן ה-{ עד ה-}) והדבק למטה
השתמש באותו קוד בכל המכשירים. שנה אותו אם תרצה להתחיל מחדש.
