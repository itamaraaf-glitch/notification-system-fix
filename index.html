הגדרה חד פעמית – 3 דקות (Firebase חינמי):
1. פתח console.firebase.google.com → צור פרויקט חדש
2. Build → Realtime Database → "Create database" → "Start in test mode"
3. העתק את כתובת הדאטאבייס (מתחילה בـhttps:// ומסתיימת בـfirebaseio.com) → הדבק למטה
אפשר למצוא אותה בקונסול Firebase: Realtime Database → כתובת בראש הדף

📲 דחיפה לטלפון גם כשהאפליקציה סגורה

ההתראות שאתה מקבל עכשיו נוצרות בתוך האפליקציה — לכן הן מופיעות רק כשהיא פתוחה.
כדי לקבל דחיפות גם כשהאפליקציה סגורה לגמרי, שרת בענן (GitHub Actions) כבר רץ אצלך כל חצי שעה — הוא רק צריך 3 מפתחות סודיים כדי לפעול. הגדרה חד-פעמית של דקה:
איפה מדביקים: GitHub → המאגר שלך → Settings → Secrets and variables → Actions → New repository secret. מוסיפים כל אחד מ-3 המפתחות הבאים (Name בדיוק כמו שכתוב, ו-Value לפי הכפתור להעתקה):
✅ אחרי שמדביקים את שלושתם — תוך חצי שעה תתחיל לקבל תקציר בוקר ותזכורות פגישה ישירות לטלפון, בלי לפתוח את המערכת.
רוצה לבדוק מיד? ב-GitHub: Actions → daily-digest → Run workflow.
